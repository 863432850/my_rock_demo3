# 碳排放对标分析报告 — 界面复刻提示词

> **数据口径（先读这条）**
>
> 1. **本企业碳排放强度只能来自入参 `emission.intensity`，一律不兜底。**
>    - **入参给 `0` 或字段缺位 → 视为"无有效数据"**（单位产品强度为 0 在业务上不成立），全篇进入无有效数据态：所有比值、排名、超越比例写 `--`；对标总览条形图不画「本企业」条；二、三、四、五各章的分析与建议改为"数据缺失"措辞。
>    - **严禁**用行业均值、相邻期插值、等比放大、联网检索来"补"一个本企业强度，也**不得**改用某个基准值代入推算。
> 2. **本企业数据只采集"单位产品碳排放强度"一项。** 年产量、年排放总量、工序级排放量在当前数据条件下**均无法获取**，因此入参**不设** `emission.annualOutput`，正文也**没有**年产量、年减排量（万tCO₂/年）这类口径。第五章只出**单位产品口径**的降碳空间（强度差距 tCO₂/t ＋ 相对降幅 %）。**不要自行补上产量或年度减排量**。
> 3. **对标基准（区域均值 / 行业均值 / 行业先进值 / 样本企业数 / 排名）属 L3 兜底生成**，按 2.5(1)(3)~(6) 的公式与稳定种子确定性生成，**不是接入的真实统计数据**；正文不得暗示这些数字来自真实报送平台。
> 4. 各基准之间必须**保持相对关系**：`advanced < indAvg`；`region = 全国` 时 `regionAvg = indAvg`。不得出现基准倒挂。
> 5. 全篇禁止出现 `NaN`、`undefined`、`Infinity`、`∞`；也禁止出现「示例」「演示」「模拟」「占位」「待补充」等字样。
> 6. 本报告只做**企业层级**对标（强度 / 排名 / 降碳空间），**不含**工序级、产品级或排放源级的分解拆解。

## 二、任务

### 数据来源与真实性要求（先读）

本报告的数字分属两层，**不要笼统写成"数据来自报送平台"**：

**A. L1 入参直取（零兜底）——本企业碳排放强度**

- `emission.intensity` → 摘要第 1 卡、各处对比小字、排名与超越比例、强度排名表「企业数据」格、条形图「本企业」条、五、降碳空间测算表。
- **入参给 `0` 或缺失就写 `--`**，不推算、不检索替换、不用行业经验值补位。详见 2.5(2)(10)(12)。
- **企业侧只有这一项数据**：年产量、年排放总量、工序级排放量一律不采集、不生成、不反推（见「数据口径」第 2 条）。

**B. L3 兜底生成——各级对标基准（区域均值 / 行业均值 / 行业先进值 / 样本企业数 / 排名）**

- 按 2.5(1)(3)~(6) 的公式与种子 `SEED = strHash(region) ^ (year × 131) ^ month` **确定性生成**，同入参同结果。
- 这些基准是**演示口径的兜底值**，用于让报告结构完整、让排名可解释；**不得**在页面上声称它们来自"区域碳排放数据报送平台""行业协会统计"等具体来源（原文案仅作为排名口径说明保留，不得扩写）。
- 基准必须满足相对关系：`advanced < indAvg`；`region = 全国` 时 `regionAvg = indAvg`。

**C. 通用禁令**

- 不得出现与入参量级明显不符的常量（如强度 0.76 tCO₂/t 的企业，报告里不得出现「强度 3.5 tCO₂/t」这类越界数字）。
- 不得把某一家企业的公开数字直接套给入参企业。
- 不得写「数据待补充」「暂无数据」「（示例）」；一律按 2.5(12) 与附录 C 规定的措辞处理。

### 2.5 数据规则（唯一数据源）

全部数值由以下规则推出。**不同入参 → 不同数据；同一入参 → 完全一致**。不要另编数字。

**(1) 稳定随机源**（原样实现，勿改）：

```javascript
function strHash(str) {                 // 区域名 → 稳定数值
  var h = 2166136261;
  for (var i = 0; i < str.length; i++) {
    h ^= str.charCodeAt(i);
    h = Math.imul(h, 16777619);
  }
  return h >>> 0;
}
function mulberry32(seed) {             // 可复现伪随机
  var a = seed >>> 0;
  return function () {
    a |= 0; a = (a + 0x6D2B79F5) | 0;
    var t = Math.imul(a ^ (a >>> 15), 1 | a);
    t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}
// 种子与随机数发生器：
var SEED = (strHash(region) ^ Math.imul(year, 131) ^ month) >>> 0;
var rnd = mulberry32(SEED);             // 下文 rnd() 按顺序依次取值
```

**(2) 本企业强度 ent**（tCO₂/t）：**直接取入参，不做任何年份折算、不做月度序列插值**。

```
ent     = round4( emission.intensity )      // 入参，4 位小数
HAS_ENT = emission.intensity 存在且 > 0
```

`HAS_ENT = false` 时，下文所有依赖 `ent` 的量（`rank` / `outperform` / `vsRegion` / `vsIndustry` / `vsAdvanced` / 降碳空间）**一律置空**、渲染为 `--`，并让相关章节进入「无有效数据」态。**不得**用任何基准值代入 `ent` 继续计算。

**(3) 行业均值 indAvg**：`round4( (0.8020 + (2026 − year) × 0.015) × (1 + (rnd() − 0.5) × 0.008) )`

**(4) 区域均值 regionAvg**：region=「全国」时偏移 0；省份时 `offset = (rnd() − 0.45) × 0.12`。`regionAvg = round4( indAvg × (1 + offset) )`

**(5) 行业先进值 advanced**：`round4( indAvg × (0.925 + rnd() × 0.01) )`

**(6) 样本企业数 entCount**：「全国」→ `round(1400 + rnd() × 900)`；省份 → `round(45 + rnd() × 180)`

**(7) 排名 rank 与超越比例 outperform**（确定性，不再取随机；**`HAS_ENT = false` 时两者均为 `--`**）：

```
rankPct    = clamp(0.5 − (regionAvg − ent) / (regionAvg × 0.22), 0.02, 0.98)
rank       = max(1, round(entCount × rankPct))
outperform = round1( (1 − rank / entCount) × 100 )   // 1 位小数
```

**(8) 差距百分比**（2 位小数，负值表示本企业更优；**`HAS_ENT = false` 时均为 `--`**）：

```
vsRegion   = round2( (ent − regionAvg) / regionAvg × 100 )
vsIndustry = round2( (ent − indAvg)    / indAvg    × 100 )
vsAdvanced = round2( (ent − advanced)  / advanced  × 100 )
```

> 以上任意一处要显示，都必须**先判断 `HAS_ENT`**。**JS 陷阱**：`null >= 0` 为 `true`、`Number(null)` 为 `0`，直接参与比较或除法会静默走到错误分支并产出 `NaN`——必须先判空再算。

```

**(9) 摘要第 6 卡判定语**：ent≤advanced→「已达行业先进水平」；ent≤indAvg→「优于行业平均、距先进有差距」；否则→「落后于行业平均，亟需提升」。ent≤indAvg 时显示绿色，否则红色。

**(10) 降碳空间测算**（**单位产品口径；企业侧没有产量数据，禁止反推**）：

```

> - 「强度差距」**保留符号**（可负；负值表示本企业已优于该档目标，绿字）；「相对降幅」**下限为 0**，已达标时写 `0.00%`（绿字）。

**(11) 数值格式**：强度类一律 4 位小数；百分比按上文位数；千分位用中文本地化（`toLocaleString('zh-CN')`）。

**(12) 零值与缺值处理（除零保护，必须实现）**

`emission.intensity` 缺省或为 `0` 属**合法输入**，报告须正常渲染，不得报错、不得留空、不得填数。分母为 `0` 时统一写 `--`：

| 情形 | 正确输出 | 错误输出（禁止） |
| --- | --- | --- |
| `intensity` 缺失或 `≤ 0` | 摘要第 1 卡数值 `--`；区域/行业/先进三卡的对比小字写「本企业数据缺失」；排名卡 `--`；超越比例 `--` | 显示 `0.0000`、拿 `0` 参与比较得出「已达行业先进水平」 |
| `intensity` 缺失时的条形图 | **不画**「本企业」条，只画三条基准条 | 画一条 0 宽的条、还把本企业排在最前 |
| `intensity` 缺失时的各章文案 | 二（一）写「本期未提供本企业碳排放强度数据，无法开展对标分析……」；三、优势与短板各写一条「数据缺失，暂不作评价」；五、降碳空间表的强度差距与相对降幅 `--`，结论改为整句提示 | 保留原对比句式却代入 `--`（会读成「优于 --%」） |

| `HAS_ENT = false` | **不计算** rank / outperform / vs* / 降碳空间 | 对 `null` 做减法，产出 `NaN` |
| `indAvg` 为 `0`（理论上不会发生） | 相关比值写 `--` | `NaN` / `∞` |

> 实现提示：判断顺序必须是「**先判 `HAS_ENT` → 再算派生量 → 最后格式化**」。格式化函数遇到 `null` / `NaN` / `Infinity` 必须返回 `--`，不得输出 `0.0000` 或 `∞`。

- 不要出现 `NaN`、`undefined`、`Infinity`、`∞`（含表格单元格、图表刻度、SVG 文本节点）。

## 附录 A · 行业锚点与量级自检

**单位产品碳排放强度（tCO₂/t）的合理区间**——用于判断入参是否"一眼假"，**不是用来填数**：

| 行业 / 工艺路线 | 单位产品碳排放强度 | 说明 |
| --- | --- | --- |
| 钢铁（长流程，高炉—转炉） | 1.8 ~ 2.32 tCO₂/t 粗钢 | 世界钢铁协会全球平均约 1.92；国家温室气体排放因子数据库（第二版）转炉粗钢直接强度约 1.6048 |
| 钢铁（短流程，电炉） | 0.63 ~ 0.76 tCO₂/t 粗钢 | 以电力间接排放为主 |
| 水泥（熟料） | 0.85 ~ 0.90 tCO₂/t 熟料 | 其中工艺过程约占 0.52 ~ 0.55 |
| 火力发电 | 0.75 ~ 0.90 tCO₂/MWh | 随煤质与机组效率波动 |
| 电解铝 | 10 ~ 13 tCO₂/t 铝（含电力间接） | 电力结构影响极大 |

> ⚠️ 上表是「每吨产品」的强度，本报告入参 `emission.intensity` 也应是**单位产品强度**。
> 若入参明显偏离所属行业区间（如钢铁企业给 0.06 或 6.0），**应如实呈现并在文案中提示存疑**，**不要**替它改成"合理值"。

**对标基准的参照**：行业均值基准取 `0.8020 tCO₂/t`（跨行业通用口径，见 2.5(3)）——本报告不区分行业，故用统一的通用基准。若改为行业专属基准，需同步调整 2.5(3) 的基准常量，并保持 `advanced < indAvg` 的相对关系。

## 附录 B · 兜底生成规则

> **适用范围：仅用于「各级对标基准」（区域均值 / 行业均值 / 行业先进值 / 样本企业数）。**
> **本企业碳排放强度一律不兜底**——见「数据口径」第 1 条。

**B1 基准的生成必须逐字按 2.5(1)(3)~(6)**

- 随机数发生器的**取值顺序不可调换**：`indAvg → regionOffset（全国时跳过）→ advanced → entCount`。
  顺序一变，同一入参的结果就会变，"同条件结果一致"的承诺随之失效。
- `region = 全国` 时**跳过** `regionOffset` 那一次 `rnd()` 取值——这是全国与省份随机序列不同的原因，务必按原文实现。

**B2 基准不得反推本企业数据**

- 任何情况下都不得用 `regionAvg` / `indAvg` / `advanced` 去"倒推"一个本企业强度。
  本企业强度只有两个合法来源：**入参**，或显式的**「无有效数据」占位 `--`**。

**B3 本企业数据缺失时的降级**

- `HAS_ENT = false` → 排名、超越比例、三类差距、降碳空间全部 `--`，相关章节走「无有效数据」措辞；
  **基准仍照常计算与显示**（它们不依赖本企业数据）。
- 基准的 `rnd()` 消耗与入参**无关**（除 `region = 全国` 跳过 `regionOffset` 那一次），
  因此「本企业强度缺失」不会让基准或样本企业数发生偏移——务必按 2.5(3) 无条件取值。
