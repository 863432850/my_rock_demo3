# 双碳管理月度简报 — 提示词

## 一、入参

```json
{
  "companyName": "河南安钢周口钢铁有限责任公司",
  "year": 2026,
  "month": 6
}
```

| 字段            | 类型     | 说明                            |
| ------------- | ------ | ----------------------------- |
| `companyName` | string | 企业名称，用于封面主标题、工具条标题            |
| `year`        | number | 报告年份（4 位）                     |
| `month`       | number | 报告月份（1–12），报告只包含 1 月至该月的年累计数据 |

## 二、任务

你只生成「双碳管理月度简报」报告页（**最终只交付一个文件：`双碳管理月度简报.html`，CSS、JS 全部内联**），不要生成任何平台导航、侧栏、菜单、卡片列表、向导。除这一个 HTML 文件外，不得再产出任何其他文件（包括 html2canvas/jspdf 等库文件、单独的 CSS/JS、说明文档）——PDF 下载所需的库必须在该 HTML 内通过 CDN `<script src>` 引用。

用户消息里的【入参】JSON 是唯一变量来源。页面中所有年月、企业名称都从入参带入；数据按本文「数据规则」生成，不要自己编其它数字。

### 做什么

画一个拟 A4 文档的网页报告（可单文件 HTML，CSS、JS 内联）。这就是用户在平台上点击某个月「查看报告」之后看到的界面。报告随 `year`、`month` 动态变化：点几月就生成几月的报告。

### 不要做什么

- 不要画平台顶部导航、侧栏、面包屑、月份卡片列表、筛选栏。
- 不要出现「熟料」「水泥」等单一行业字眼，报告对单个企业通用（用「产品产量」「单位产品碳排放强度」这类通用措辞）。
- 不要编制说明、版权尾注、编制单位、编制日期落款。封面只保留数据期间。
- 不要弹窗、toast、编辑功能、删除按钮。
- 不要用 emoji。
- 不要假设月份：报告数据只覆盖 `year-01` 至 `year-{month}`，不要展示入参月份之后的行。

### 摘要 · 本月核心指标概览

6 张 KPI 卡，3 列网格，卡片浅绿渐变底（`#f4fbf6`→白）、1px 浅绿边、圆角 8px；指标名 12px 灰，数值 20px 加粗，单位小字；底部一行同比/环比（▲▼，上涨红 `#d4380d`、下跌绿 `#2ba471`，与明细表口径一致：对排放类指标，数值上升为红、下降为绿）：

| 卡 | 指标名             | 数值                   | 小字行               |
| - | --------------- | -------------------- | ----------------- |
| 1 | 本月碳排放量          | 当月值（万t，2 位小数）        | 环比（1 月显示「全年开局基线」） |
| 2 | 年累计碳排放量         | 入参月累计值（万t）           | 同比                |
| 3 | 碳排放强度           | 入参月累计值（tCO₂/t，4 位小数） | 同比                |
| 4 | 原料替代率（Wt 用量法）   | 入参月累计值（%）            | 同比                |
| 5 | 燃料替代率（TSR 热量替代） | 入参月累计值（%）            | 同比                |
| 6 | 配额盈缺（全年预测口径）    | 核发量 − 全年预测排放量（万t）    | 固定文案「盈余，碳资产总体充裕」  |

卡下方左右两栏（左 1.2 : 右 1，右栏左虚线分隔）：

- 左「本月要点」4 条无序列表，数字由数据计算：
  1. 本月碳排放量 X 万t，环比 ±x%（1 月写「为全年开局基线」）；年累计排放 X 万t，同比 ±x%。
  2. 碳排放强度 X tCO₂/t，目标达成率 x%，强度控制总体平稳。
  3. 原料替代率（Wt）x%、燃料替代率（TSR）x%，替代水平同比仍有提升空间。
  4. 按全年预测口径测算，配额盈余约 X 万t，履约压力总体可控。
- 右「本月排放结构」环形图（donut）：直接排放（燃料燃烧、工业过程）占 60%–68%（按月取一个稳定比例即可）、间接排放（外购电力、热力）占其余部分；中心显示「本月排放（万t）」与数值；图例带色点、数值（万t）和占比。

### 章节标题样式

- 一级标题（一、碳排放…）：21px，左 5px 主色竖条，背景 `#e9f7ee` 向右渐隐，如 `一、碳排放`。
- 二级标题（（一）…）：16.5px，前置 8px 主色小方块。
- 正文段落 13.5px，关键数字用主色 `<strong>`。

### 一、碳排放

**（一）碳排放总量**：一段文字「目标达成率：xx%」（取 ACHIEVE.total）；趋势折线图「（图）碳排放总量趋势」；明细表「碳排放总量明细表（年累计）」，单位 万t。

**（二）碳排放强度**：同上结构，达成率取 ACHIEVE.intensity；图「（图）碳排放强度趋势」；表「碳排放强度明细表（年累计）」，单位 tCO₂/t（4 位小数）。

### 二、碳减排

**（一）原料替代率**：先一段叙述——  
`目标达成率：xx%，年累计值（Wt 用量法）：x %，年累计值（CC 成分法）：x %，目标值（Wt 用量法）：-- %；年累计替代原料用量：x 万t。`  
然后两组「趋势图 + 明细表」：原料替代率（Wt 用量法）、原料替代率（CC 成分法），单位均为 %。

**（二）燃料替代率**：同构，叙述——  
`目标达成率：xx%，年累计值（TSR 热量替代）：x %，年累计值（CS 燃煤替代）：x %，目标值（TSR 热量替代）：-- %；年累计替代燃料用量（含煤矸石）：x 万t。`  
两组图 + 表：燃料替代率（TSR 热量替代）、燃料替代率（CS 燃煤替代），单位 %。

### 三、碳资产

### 四、碳交易

**（一）交易概览**：两段文字 + 横向条形图「碳交易买入 / 卖出统计（{year} 年累计）」。

- `{year}年碳资产交易买入：交易总量 X 万t，交易总额：X 万元；其中大宗协议交易总量：0.00 万t，挂牌交易：X 万t；`
- `{year}年碳资产交易卖出：交易总量 X 万t，交易总额：X 万元；其中大宗协议交易总量：0.00 万t，挂牌交易：X 万t。`
- 买入量：`month < 8` 为 0，否则 `0.1 × (month − 7)`；卖出量：`max(0, 0.30 + (month − 6) × 0.05)`（6 月恰为 0.30）；金额 = 量 × 本月全国碳市场日均价。条形图四项：买入挂牌（蓝）、买入大宗（浅蓝）、卖出挂牌（绿）、卖出大宗（浅绿）。

**（二）碳市场行情**：说明文字 + 汇总表 + 全国碳市场 3 张折线图 + 地方碳市场条形图 + CCER。

- 说明：`数据来源于各碳市场，每日数据更新；` `数据获取范围 YYYY-MM-01 至 YYYY-MM-月末，共有 N 个交易日`（N = 当月工作日天数）。
- 汇总表 8 列：`碳市场 | 交易量（万吨）| 交易额（万元）| 日均价（元/吨）| 开盘价波动范围（元/吨）| 最高价（元/吨）| 最低价（元/吨）| 收盘价波动范围（元/吨）`，8 个市场各一行（全国/上海/北京/广东/湖北/重庆/天津/福建），表下注「“--”表示该区间内无成交数据。」
- `详细报告如下：` → `全国碳市场` → 三张折线图：`01、开盘价与收盘价（元/吨）`（蓝+绿双线）、`02、最高价与最低价（元/吨）`（红+青双线）、`03、日成交均价（元/吨）`（橙单线），X 轴为该月每个交易日（MM-DD）。
- `地方碳市场` → 横向条形图「（图）地方碳市场成交量（本月累计）」，7 个地方市场。
- `CCER 成交情况` → 单月：`成交均价为 X 元/吨。成交总量为 X 万t。` + 条形图；双月：`成交均价为 --。成交总量为 --。` + 空条形图（本月无成交）。

### 五、月度分析与工作建议

**（一）月度分析** 4 条无序列表（数字由数据计算，措辞按同比涨跌自动选择）：

1. 排放走势：年累计排放量、高于/低于去年同期 x%，按涨跌接「主要受生产负荷提升影响，需关注后续月度排放增量。」或「排放管控成效持续显现。」
2. 强度与目标：强度达成率、总量达成率，总量达成率 ≥ month÷12×100 写「总体符合时间进度要求」，否则写「总量进度略慢于时间进度，下半年需加强管控」。
3. 减排结构：原料替代率同比、燃料替代率同比，结尾固定「替代原料、替代燃料推广仍需加快」。
4. 碳资产与交易：本月全国碳市场日均成交价 X 元/t，配额处于盈余状态，可结合行情择机开展交易，盘活碳资产。

**（二）下月工作建议** 5 条编号卡片（绿色圆形序号，浅底圆角条），固定文案：

1. 加强重点用能设备与主要工序的能耗、排放月度监测，完善碳排放数据台账与质量控制，确保数据真实、准确、可追溯。
2. 持续优化原料、燃料结构，提高替代原料与替代燃料使用比例，进一步降低单位产品碳排放强度。
3. 扩大绿电、绿证采购规模，推进厂区分布式光伏等清洁能源项目建设，降低间接排放占比。
4. 密切跟踪全国碳市场行情，结合配额盈缺状况合理安排交易节奏，提前谋划年度履约工作。
5. 推进节能技术改造与余热、余压回收利用，深入挖掘各工序节能降碳潜力。
