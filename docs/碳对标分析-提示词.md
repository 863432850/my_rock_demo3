## 一、入参

```json
{
  "companyName": "河南安钢周口钢铁有限责任公司",
  "currentYear": 2026,
  "currentMonth": 9,
  "defaultRegion": "河南省"
}
```

### 入参带入规则

| JSON 字段       | 影响位置                                      | 规则                                                                                                              |
| ------------- | ----------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| companyName   | 业务主体标识 / 「开始对标」跳转参数 / defaultRegion 的取值依据 | 本查询界面本体不直接展示企业名，但它是本次对标的主体：**跳转报告页时必须作为 `company` 参数透传**（见 2.5(4)）；同时 defaultRegion 应取该企业所在省（示例企业为河南省企业，故默认河南省） |
| currentYear   | 「对标年」下拉的可选范围与默认选中项                        | 下拉列出 currentYear ~ currentYear-4 共 5 项（倒序），默认选中 currentYear                                                     |
| currentMonth  | 「对标月」下拉的默认选中项                             | 下拉固定 1~12 月，默认选中 currentMonth                                                                                   |
| defaultRegion | 「对标区域」下拉的默认选中项                            | 取值必须是 2.5 中区域清单里的一项，取 companyName 所在省份                                                                          |

### 2.5 数据规则（唯一数据源）

**(1) 对标年下拉**：`cond-year`，列出 currentYear、currentYear-1、…、currentYear-4 共 5 项（倒序），每项显示为「{y} 年」、value 为年份数字字符串；默认选中 currentYear（入参示例值下即：2026 年 / 2025 年 / 2024 年 / 2023 年 / 2022 年，默认 2026 年）。

**(2) 对标月下拉**：`cond-month`，固定 1~12 共 12 项，显示为「{m} 月」、value 为月份数字字符串；默认选中 currentMonth（入参示例值下默认 9 月）。

**(3) 对标区域下拉**：`cond-region`，固定 35 项，顺序与内容**逐字**如下（首项为「全国」，其余为 34 个省级行政区）：

```
全国
北京市、天津市、河北省、山西省、内蒙古自治区
辽宁省、吉林省、黑龙江省
上海市、江苏省、浙江省、安徽省、福建省、江西省、山东省
河南省、湖北省、湖南省、广东省、广西壮族自治区、海南省
重庆市、四川省、贵州省、云南省、西藏自治区
陕西省、甘肃省、青海省、宁夏回族自治区、新疆维吾尔自治区
台湾省、香港特别行政区、澳门特别行政区
```

显示文字与 value 均为区域名本身；默认选中 defaultRegion（入参示例值下默认「河南省」，即 companyName 所在省份）。

**(4) 「开始对标」点击逻辑**：

1. 读取三个下拉的 value；
2. 若任一为空 → toast 提示「请先选择完整的对标条件」，不跳转；
3. 否则跳转到：`benchmark-report.html?type=emission&company={companyName}&year={year}&month={month}&region={region}`，其中 company/year/month/region 均做 `encodeURIComponent`（company 取入参 companyName，原样透传给报告页作为报告主体）。

**(5) 页签切换**：纯前端 display 切换，无网络请求；「碳资产对标」页签永远显示建设中占位，不要为它做任何真实功能。

**声明：本节是唯一数据源，生成时不要另编下拉项、不要增删区域。**
