# 智能减排寻优 — 入参格式 + 固定提示词

发给其他大模型时，拼成两段即可：

1. **入参**：研发按下面格式填好（每次可变）
2. **提示词**：后面「固定提示词」整段复制（不要改）

不要把碳目标制定第一步、第二步、工具栏入口发给模型。模型只生成 **点击「智能减排寻优」之后** 的那一屏。

---

## 一、入参格式（研发填写）

只填这一块。字段名不要改。用不到的字段填 `null`。

`indicators` 只传指标名称字符串，1 个、2 个、3 个或更多都可以。界面和方案只认这次列表，有几条就用几条。

```json
{
  "industry": "钢铁行业",
  "dimension": "年度",
  "year": 2027,
  "month": null,
  "name": "2027年碳目标",
  "indicators": ["碳排放总量", "碳排放强度"]
}
```

字段说明：

| 字段 | 必填 | 取值 | 界面上怎么用 |
|---|---|---|---|
| `industry` | 是 | 用户所在行业中文名 | 顶栏「用户所在行业」；方案措施按该行业生成 |
| `dimension` | 是 | `年度` 或 `月度` | 顶栏「时间维度」；月度偏当月可做，年度偏纳入计划 |
| `year` | 是 | 四位年份数字 | 顶栏「目标年份」 |
| `month` | 月度必填 | `1`–`12`，年度时填 `null` | 月度时年份展示为 `2027年8月` |
| `name` | 否 | 目标名称 | 不在寻优界面展示，写入下载报告 |
| `indicators` | 是 | 指标名称字符串数组，至少 1 条 | 顶栏「所选指标」按顺序顿号连接；方案正文只对照这些名称 |

发给模型时推荐这样包一层（入参换成当次 JSON）：

````text
【入参】
```json
{这里粘贴上面填好的 JSON}
```

【任务】
（下面「固定提示词」全文）
````

## 二、固定提示词（复制从下一行到文末「提示词结束」）

你只生成「智能减排寻优」全屏方案页，不要生成任何入口、向导、第一步、第二步、工具栏、目标填报表格。

用户消息里的【入参】JSON 是唯一数据源。布局和交互按下面规格执行；方案文字（措施名、说明、要点）由你根据入参自行撰写，不要套用固定行业措施清单。

### 做什么

画一个铺满视口的单页（可单文件 HTML+CSS+JS）。这就是用户点「智能减排寻优」之后看到的界面。

### 不要做什么

- 不要画碳目标制定列表、第一步、第二步、上传/导入/导出。
- 不要出现目标值、实际值、预测排放、减排吨数、差异率。预计降碳只用百分比，不要写吨。
- 不要写产品说明句，例如「三类减排机理通用」「仅作路径学习」「不回写填报数据」。
- 不要底部操作栏、弹窗、侧栏、平台导航。
- 不要假设指标数量或名称。只用入参里实际给出的 `indicators` 字符串。

### 页面结构（必须）

```
┌──────────────────────────────────────────────────────┐
│ 智能减排寻优                    [返回] [下载报告]    │  高约 52px，白底
├──────────────────────────────────────────────────────┤
│ 用户所在行业 │ 时间维度 │ 目标年份 │ 所选指标        │  一行四列
│ {industry}   │ {dimension}│ {year}年[月] │ {指标名}  │
│                                                      │
│ ┌────────────┐ ┌────────────┐ ┌────────────┐         │
│ │01 能效提升  │ │02 能源替代  │ │03 工艺与结构│         │
│ │   预计降碳  │ │   预计降碳  │ │   预计降碳  │         │
│ │     x%–y%  │ │     x%–y%  │ │     x%–y%  │         │
│ └────────────┘ └────────────┘ └────────────┘         │
│                                                      │
│ {当前类 intro}                                       │
│ 建议路径                                             │
│  01 [工序] 措施标题                      优先级      │
│     说明 / 实施要点 / 与所选指标的关系               │
└──────────────────────────────────────────────────────┘
```

顶栏：左「智能减排寻优」；右「返回」「下载报告」，返回在左、下载在右。

入参条从【入参】读取：

- 用户所在行业 = `industry`
- 时间维度 = `dimension`
- 目标年份 = 年度 `{year}年`；月度 `{year}年{month}月`
- 所选指标 = `indicators` 按数组顺序用顿号连接。有几条展示几条；空数组时显示 `--`

### 三类方案（分类名称固定，正文不固定）

不要用保守/均衡/进取，也不要用运行优化/重点技改/结构转型。卡片永远这三类：

| 序号 | 名称 | 标签 | 机理（写 intro 时用，不要当措施清单） |
|---|---|---|---|
| 01 | 能效提升 | 当期可做、低投入 | 把现有用能做少、做精，不先改工艺路线 |
| 02 | 能源替代 | 周期内可安排、需资源匹配 | 用更低碳的电、热、燃料替换高碳能源 |
| 03 | 工艺与结构 | 中长期、需条件评估 | 调整原料、工艺路线或产品结构 |

每张方案卡右侧必须展示「预计降碳」+ 百分比区间（如 `5%–8%`）。数字不从入参读取，由你根据 `industry`、`dimension` 和本次指标自行估算：

- 口径：相对当期排放的预计降幅，不是吨、不是目标值。
- 三类要能区分：能效提升通常最低，能源替代居中，工艺与结构弹性最大。
- 月度区间明显小于年度；不同行业不要写成同一组数。
- 用整数百分比区间，不要假精度（如 6.37%）。
- 不要把三类百分比加总当成总降碳。

默认选中：`dimension` 为 `月度` 选能效提升，为 `年度` 选能源替代。点击卡片只切换下方 intro 和路径，三类卡片始终都在。

intro 用入参拼接，不要加产品口号：

面向{industry}、{年份周期}。{该类一句话机理}。该类预计降碳 {x%}–{y%}。{月度：措施侧重当月可执行；年度：可按年内节奏安排}。本次对照指标：{indicators 全部名称，顿号连接}。

### 路径内容（结构固定，文字由你生成）

每类给出若干条路径（建议 2～4 条）。每条必须有这些字段，文案按入参撰写：

- 工序标签：该行业真实工序或环节
- 措施标题
- 优先级：优先实施 / 协同实施 / 条件成熟后推进
- 详细说明
- 实施要点 2～3 条（月度写「当月…」，年度写「纳入年度计划…」）
- 与指标关系：只对照本次 `indicators` 里的名称。写清这条措施主要支撑其中哪些；不要引用入参里没有的指标。

撰写要求：

- 紧扣 `industry` 的行业常识，措施要像该行业能落地的动作，不要写成万能套话。
- 紧扣本次传入的指标：指标少就写得更聚焦，指标多就分别点到。
- 同类三条路径不要重复同一句话换皮。
- 三类之间不要互相抄措施。
- 不要出现吨、目标值、预测值。降碳只允许用三类方案卡上的预计百分比。
- 不要使用任何预置措施清单；同一行业、不同指标组合，写出的路径可以不同。

### 返回、下载

- 返回：关闭本页。独立 HTML 预览可用 `history.back()`，无历史则隐藏根节点。不要跳向导。
- Esc：等同返回。
- 下载报告：打开浏览器打印，toast「请在打印窗口中选择「存储为 PDF」完成下载」。报告标题「智能减排寻优方案报告」，先打印入参（行业、时间维度、目标时间、所选指标、目标名称 `name`、生成时间），再打印三类方案全文。每类标题旁带「预计降碳 x%–y%」。报告同样不要目标值/实际值/预测排放/吨数，指标只打入参里有的。

### 视觉

紧凑、少留白、不要渐变和大阴影、不要 emoji。

- 主色 `#00a854`，深绿 `#00964c`，浅绿 `#e8f8ee`
- 文字 `#303133` / `#606266` / `#909399`
- 页面底 `#f6f8fa`，卡片白，边 `#e6eaee`，圆角 6px
- 选中方案卡：绿边 + 底 `#f4faf6` + 左侧 3px 主色条
- 预计降碳数字：卡片右侧，标签 11px 灰色，数值约 20px、加粗、主色 `#00a854`
- 工序标签浅绿底深绿字；路径序号 28px 圆
- 内容左右约 20px，模块间距约 12px，全宽不要居中窄栏
- 返回用线框按钮，下载报告用主色按钮

直接输出可运行的完整 HTML（CSS、JS 内联即可）。不要解释，不要生成向导页。

提示词结束
