**(5) 一、报告定位与核心思路**（三段，成文模板）

- 段 1：「本报告为 {companyName} 专属碳资产对标专项报告，聚焦企业碳资产的**规模、结构与运营绩效**开展量化研判，与碳排放对标（强度/减排）形成互补——碳排放对标看「排了多少、强度如何」，本看「手里有多少碳资产、运营得好不好」。报告以「{region}」为对标区域、以「{year}年{month}月」为对标期间，将本企业碳资产总价值与区域平均值、行业平均值、行业先进值进行四维对比，并延伸至配额覆盖率、碳资产收益率等运营指标。」
- 段 2：「报告核心思路：**一排名、二对比、三结构、四建议**——先以碳资产规模排名锚定企业在区域同行业中的位置；再与区域、行业、先进三级基准逐层对比；拆解配额、CCER、其他碳资产的配置结构并评价运营绩效；最终给出碳资产优化与履约保障建议，为企业盘活碳资产、增厚碳收益提供决策依据。」
- 段 3：「数据口径说明：碳资产价值按持仓量 × 当期市场参考价折算（配额 90 元/tCO₂、CCER 68 元/tCO₂）；区域与行业数据来源于区域碳排放权登记簿、碳交易结算平台及行业协会统计，样本企业 {entCount} 家；先进值取行业前 10% 企业水平。」

**(6) 二、企业碳资产规模与结构对标**

1. **排名表**（表题「企业碳资产规模对标表」，右上单位「单位：万元」）：表头 `企业层级 | 企业数据 | {region}排名 | {region}平均值 | 行业平均值 | 行业先进值`，仅 1 行数据：`碳资产总价值 | {entTotal}（橙底高亮） | {rank} / {entCount}（橙底高亮） | {regionTotalAvg} | {indAvgTotal} | {advancedTotal}`。表注：「注：排名按碳资产总价值降序（价值越高排名越靠前），样本为{region}同行业报送企业。」
2. **（一）资产规模与对标分析**：一段成文，模板：  
   「本企业碳资产总价值 {entTotal} 万元，高于/低于{region}平均值 {regionTotalAvg} 万元（高出/低于区域 {abs(vsRegion)}%），高于/低于行业平均值 {indAvgTotal} 万元（高出/低于行业 {abs(vsIndustry)}%），[已达到行业先进值 {advancedTotal} 万元水平 / 与行业先进值 {advancedTotal} 万元相比仍有 {vsAdvanced}% 差距]。在{region} {entCount} 家同行业样本企业中位列第 **{rank}** 名，超越区域内 {outperform}% 的企业，{梯队判定语}」  
   梯队判定语（按 outperform）：≥75→「整体处于区域头部梯队，碳资产厚度与运营能力领先。」；≥50→「整体处于区域中上水平，资产规模仍有向头部企业看齐的空间。」；≥25→「整体处于区域中游偏下位置，碳资产储备需系统补充。」；否则→「整体处于区域落后梯队，碳资产储备薄弱，须尽快充实以提升履约与交易弹性。」

### 2.5 数据规则（唯一数据源）

全部数值由以下代码推出。**不同入参 → 不同数据；同一入参 → 完全一致**。不要另编数字。

**(1) 稳定随机源**（原样实现，勿改）：

```javascript
function strHash(str) {                 // 区域名 → 稳定数值
  var h = 2166136261;
  for (var i = 0; i < str.length; i++) {
    h ^= str.charCodeAt(i);
    h = Math.imul(h, 16777619);
  }
  return h >>> 0;
}
function mulberry32(seed) {             // 可复现伪随机
  var a = seed >>> 0;
  return function () {
    a |= 0; a = (a + 0x6D2B79F5) | 0;
    var t = Math.imul(a ^ (a >>> 15), 1 | a);
    t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}
```

**(2) 常量**：

```
CARBON_PRICE    = 90      // 元/tCO₂，配额市场参考价
CCER_PRICE      = 68      // 元/tCO₂，CCER 市场参考价
ANNUAL_EMISSION = 6058    // 万tCO₂，本企业年度履约排放
```

**(3) 基准数据计算（按以下顺序逐字实现；`rnd()` 的**调用顺序**直接决定结果，不得增删或调换）**：

> 舍入辅助：`r0 = n => +Number(n).toFixed(0)`、`r1 = n => +Number(n).toFixed(1)`、`r2 = n => +Number(n).toFixed(2)`、`round = Math.round`。

```javascript
var IS_NATIONAL = (REGION === '全国');
var SEED = (strHash(REGION) ^ Math.imul(Y, 131) ^ Math.imul(M, 977)) >>> 0;
var rnd  = mulberry32(SEED);

// —— 1) 本企业持仓量与价值 ——
var entAllowance    = r0(ANNUAL_EMISSION * (1 + (rnd() - 0.5) * 0.05));   // 配额持仓 万tCO₂
var entAllowanceVal = r0(entAllowance * CARBON_PRICE);                    // 配额价值 万元（万t × 元/t = 万元）
var entCCER         = r0((entAllowance * 0.08) * (1 + (rnd() - 0.5) * 0.3)); // CCER 储量 万t
var entCCERVal      = r0(entCCER * CCER_PRICE);                           // CCER 价值 万元
var entOther        = r0(entAllowanceVal * 0.06 * (1 + (rnd() - 0.5) * 0.4)); // 其他碳资产 万元
var entTotal        = entAllowanceVal + entCCERVal + entOther;            // 碳资产总价值 万元

// —— 2) 基准值 ——
// 注意：region='全国' 时三元短路，本行【不消耗】rnd() 调用，后续随机序列随之偏移
var regionOffset   = IS_NATIONAL ? 0 : (rnd() - 0.45) * 0.12;
var regionTotalAvg = r0(entTotal * (1 + regionOffset));                   // 区域均值 万元
var indAvgTotal    = r0(entTotal * (1 + (rnd() - 0.42) * 0.10));          // 行业均值 万元
var advancedTotal  = r0(indAvgTotal * (0.92 + rnd() * 0.02));             // 行业先进值 万元

// —— 3) 运营指标 ——
var entROI      = r2(8 + (rnd() - 0.5) * 6);                              // 本企业碳资产收益率 %
var regionROI   = r2(entROI * (1 + (rnd() - 0.5) * 0.10));                // 区域均值 %
var indROI      = r2(entROI * (1 + (rnd() - 0.30) * 0.12));               // 行业均值 %
var advancedROI = r2(indROI * 1.15);                                      // 行业先进 %
var entCoverage = r1(entAllowance / ANNUAL_EMISSION * 100);               // 配额履约覆盖率 %

// 该值本报告不展示，但【必须保留此行的 rnd() 消耗】，否则后续 entCount 会错位
var _entAssetRatio = r2(1.5 + (rnd() - 0.5) * 0.8);

// —— 4) 样本与排名 ——
var entCount = IS_NATIONAL ? Math.round(1400 + rnd() * 900)
                           : Math.round(45 + rnd() * 180);

var rankPct    = Math.min(0.98, Math.max(0.02,
                   0.5 - (entTotal - regionTotalAvg) / (regionTotalAvg * 0.22)));
var rank       = Math.max(1, Math.round(entCount * rankPct));
var outperform = r1((1 - rank / entCount) * 100);                         // 超越比例 %

// —— 5) 差距百分比（2 位小数；正值=本企业高于基准=好） ——
var vsRegion   = r2((entTotal - regionTotalAvg) / regionTotalAvg * 100);
var vsIndustry = r2((entTotal - indAvgTotal)    / indAvgTotal    * 100);
var vsAdvanced = r2((entTotal - advancedTotal)  / advancedTotal  * 100);
```

**(4) 第五章潜力测算**：

```
gap            = max(0, ANNUAL_EMISSION − entAllowance)      // 履约缺口 万tCO₂
costToFull     = r0(gap * CARBON_PRICE)                      // 补缺口成本 万元
roiGap         = max(0, advancedROI − entROI)                // 收益率差距 %（2 位小数参与运算）
gainToAdvanced = r0(roiGap / 100 * entTotal)                 // 增量年收益 万元/年
```
