**(6) 二、企业层级碳排放强度对标**

1. **排名表**（表题「企业层级碳排放强度排名表」，右上单位「单位：tCO₂/t」）：表头 `企业层级 | 企业数据 | {region}排名 | {region}平均值 | 行业平均值 | 行业先进值`，仅 1 行数据：`企业层级 | {ent}（橙底高亮） | {rank} / {entCount}（橙底高亮） | {regionAvg} | {indAvg} | {advanced}`。表注：「注：排名按碳排放强度升序（强度越低排名越靠前），样本为{region}同行业报送企业。」
2. **（一）数据分析**：一段成文，模板：  
   「本企业碳排放强度 {ent} tCO₂/t，低于/高于{region}平均值 {regionAvg} tCO₂/t（优于/超出区域 {abs}%），低于/高于行业平均值 {indAvg} tCO₂/t（优于/超出行业 {abs}%），[已达到行业先进值 {advanced} tCO₂/t 水平 / 与行业先进值 {advanced} tCO₂/t 相比仍有 {vsAdvanced}% 差距]。在{region} {entCount} 家同行业样本企业中位列第 **{rank}** 名，超越区域内 {outperform}% 的企业，{梯队判定语}」  
   梯队判定语（按 outperform）：≥75→「整体处于区域头部梯队，碳绩效管理水平领先。」；≥50→「整体处于区域中上水平，仍有向头部企业看齐的空间。」；≥25→「整体处于区域中游偏下位置，强度管控需系统加强。」；否则→「整体处于区域落后梯队，节能降碳形势严峻，须尽快采取专项措施。」
3. **（二）建议方案**：一段，模板：「结合企业碳强度对标结果，建议：{vsAdvanced>0 ? '以行业先进值 {advanced} tCO₂/t 为目标值，制定年度强度下降路线图，明确责任部门与时间节点，分阶段压降单位产品碳排放；' : '巩固行业先进水平，持续跟踪区域头部企业动态，防止强度反弹；'}建立「月度对标、季度评估」机制，将强度指标纳入企业绩效考核；积极申报国家及省级节能降碳专项资金，借力政策工具加快技改落地。」


**(7) 三、优势与短板**（左右双栏，优势绿栏、短爆红栏，各栏标题 14.5px + 无序列表 12.5px）

- 优势栏条目按条件生成（满足才列）：
  1. vsRegion≤0：「碳排放强度优于{region}平均值 {abs(vsRegion)}%，区域碳绩效处于靠前位置（第 {rank} / {entCount} 名）。」
  2. vsIndustry≤0：「碳排放强度优于全国行业平均值 {abs(vsIndustry)}%，具备行业层面的碳竞争力。」
  3. vsAdvanced≤0：「已达到行业先进值水平（{advanced} tCO₂/t），跻身行业碳效第一梯队。」
  4. outperform≥75：「超越区域内 {outperform}% 的同行业企业，碳排放管控体系成熟、执行力强。」
  5. 一条都不满足：「本期指标未优于各级对标基准，暂无可列优势项，需全面整改提升。」
- 短板栏条目按条件生成：
  1. vsIndustry>0：「碳排放强度高于全国行业平均值 {vsIndustry}%，整体能效与碳效水平落后。」
  2. vsRegion>0：「碳排放强度高于{region}平均值 {vsRegion}%，区域排名靠后（第 {rank} / {entCount} 名），面临区域碳预算与督查压力。」
  3. vsAdvanced>0：「与行业先进值相比仍有 {vsAdvanced}% 差距，先进节能降碳技术应用不足。」
  4. 0<outperform<50：「仅超越区域内 {outperform}% 的企业，与头部梯队存在系统性差距。」
  5. 一条都不满足：「各项指标均优于对标基准，暂无显著短板，需防范强度反弹风险。」
