### 2.7 数据规则（唯一数据源）

**本节是唯一数据源。数值与算法部分不要另编数字；行业内容部分严格按 (2) 的行业映射取值，不要把一个行业的排放源写到另一个行业的报告里。**

**(1) 月度排放基础数据（年累计，万t，1~12 月）**——所有行业共用的演示基线，不随行业变化：

```js
CUM_CUR  = [212.47, 422.89, 812.09, 1369.79, 1987.13, 2547.61, 3122.81, 3720.91, 4287.31, 4876.21, 5447.51, 6058.01]; // 本期年累计
CUM_PREV = [199.38, 314.34, 712.01, 1342.22, 1933.17, 2345.35, 2758.17, 3188.17, 3593.17, 4038.17, 4458.17, 4918.17]; // 去年同期年累计
monthVal(cum, i) = i === 0 ? cum[0] : +(cum[i] - cum[i-1]).toFixed(2)   // 第 i+1 月当月排放量
```

- CUR_MONTH = monthVal(CUM_CUR, month-1)；PREV_YEAR_MONTH = monthVal(CUM_PREV, month-1)；PREV_MONTH = month==1 ? null : monthVal(CUM_CUR, month-2)
- YOY = (CUR_MONTH − PREV_YEAR_MONTH) ÷ PREV_YEAR_MONTH × 100；MOM = (CUR_MONTH − PREV_MONTH) ÷ PREV_MONTH × 100

**(3) 日级排放与异动生成算法**（对任意 {year, month} 执行；伪随机必须用下方 mulberry32，seed = year×100+month，保证跨实现一致。排放源与归因按下标从所属行业的列表中取，同一入参结果完全一致）：

```js
function mulberry32(seed) {
  var a = seed >>> 0;
  return function () {
    a |= 0; a = (a + 0x6D2B79F5) | 0;
    var t = Math.imul(a ^ (a >>> 15), 1 | a);
    t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}

// days = 当月天数；total = monthVal(CUM_CUR, month-1)；base = total×10000÷days（月日均，t）
// rnd = mulberry32(year*100 + month)
// 1) 正常日：daily[d] = base × (0.95 + rnd()×0.10)，d=1..days
// 2) 注入异动 count = 4 + floor(rnd()*4) 天：
//    - day = 1 + floor(rnd()*days)，重复则 day = day%days + 1 直到唯一
//    - up = rnd() < 0.7（70% 向上）；dev = (15.5 + rnd()*22.5) × (up ? 1 : -1)
//    - daily[day-1] = base × (1 + dev/100)
//    - 排放源：roll=rnd() 按所属行业排放源表累积权重命中
//    - 等级：|dev|≥30→重大(3)，≥22→较大(2)，否则→一般(1)
//    - 归因：up 从所属行业 UP 池、否则 DOWN 池中 floor(rnd()*长度) 取一条
// 3) 异动事件按 day 升序即清单
```

**(4) 排放源结构数据**：`rnd2 = mulberry32(year*100 + month + 9)`，每源值 = `CUR_MONTH × 权重 × (0.92 + rnd2()×0.16)`（2 位小数，万t）。上月对比值 = `PREV_MONTH × 权重`（2 位小数）。

**(5) 上月闭环**：上月异动清单用同一算法以 seed = year×100+(month−1) 生成（同一行业），取事件数；closed/rate 按 2.6 第五章规则。

**(6) 数字格式**：千分位；万t 一律 2 位小数；t/日取整；偏离度/同比/环比 1~2 位小数按各处标注；百分比带正负号（正数补 +）。
